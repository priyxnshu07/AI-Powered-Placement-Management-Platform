# PlacementAI frontend

React + TypeScript + Vite single-page app for the placement platform.

See the [project README](../README.md) for the full picture: architecture, live demo, local setup and CI/CD.

```bash
cp .env.example .env   # VITE_API_URL points at the backend, e.g. http://localhost:3000/api
npm install
npm run dev            # http://localhost:5173
npm run lint
npm run build
```
